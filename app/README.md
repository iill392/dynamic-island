# 灵动岛 · Dynamic Island (Android)

一个从零实现的 Android 灵动岛（Dynamic Island）App，按用户提供的三段真机录屏 **1:1 还原** 三种效果：

| 效果 | 参考录屏 | 实现状态 |
|---|---|---|
| 充电 | `044c5d2a…mp4`（1920×342, 30fps, 10.8s） | ✅ 圆点出现 → 胶囊展开 → 正在充电 65% → 快速充电 65.5x%（双闪电 + 一次性光爆）→ 超快充电 → 内容瞬间消失、收缩成圆点后消失 |
| 系统时钟计时 | `3b4401a7…mp4`（3256×1080, 30fps, 6.5s） | ✅ 橙色秒表胶囊 ⇄ 展开大卡片（大号计时 + 秒表标签 + 播放/暂停圆钮），收起为「内容消失→0.244W 空胶囊→胶囊」的两段式 |
| 音乐播放 | `d78d986f…mp4`（2118×1080, 30fps, 16.3s） | ✅ 专辑封面 + 5 根红粉波形胶囊 ⇄ 展开播放器（封面/标题/歌手/进度条/五个控制按钮 + 封面取色的红色氛围光），两段式收起 |

同时逆向分析了参考 App（`base.apk` = **com.jamworks.dynamicspot v1.88**）的完整 UI 规格用于交叉校验
（窗口参数、布局 dp、颜色、动画插值器），分析结果在 `../analysis/apk/`；
三段录屏的逐帧测量报告在 `../analysis/video/`。

## 目录结构

```
app/                          Android 工程（Gradle 8.9 + AGP 8.7.3，Java，无第三方依赖）
  app/src/main/java/com/lingdong/island/
    MainActivity.java          控制面板：授权、启停、三种效果一键预览
    IslandService.java         前台服务：悬浮窗、状态机、充电/计时器/音乐监听
    IslandView.java            全部绘制与动画（Canvas 手绘 + 逐帧尺寸动画）
    IslandSpec.java            所有尺寸/颜色/时长/曲线（按录屏比例标定，便于微调）
    IslandData.java            三种状态的数据模型
    Curves.java                弹簧/贝塞尔插值器（与实测曲线拟合）
    IslandBus.java             NotificationListener → Service 的事件总线（含通知缓存回放）
    IslandNotificationListener.java  通知监听（系统时钟计时器、MediaSession 授权）
```

## 构建

需要 JDK 17+ 与 Android SDK（compileSdk 35）。

```bash
# 本机已配置的 gradle（本仓库开发环境）
E:\voice\tools\gradle-8.9\bin\gradle.bat -p E:\voice\app :app:assembleDebug
# 或使用工程内 wrapper（首次会下载 Gradle 8.9）
cd E:\voice\app && .\gradlew.bat :app:assembleDebug
```

产物：`app/app/build/outputs/apk/debug/app-debug.apk`（另已拷贝到 `dist/灵动岛-debug.apk`）

安装（手机开启 USB 调试后）：

```bash
adb install -r E:\voice\dist\灵动岛-debug.apk
```

## 使用（真机）

1. 打开 App →「授予悬浮窗权限」→「授予通知使用权」（计时器/音乐需要）。
2. 点「开启灵动岛」。
3. 点「充电动效 / 系统时钟计时 / 音乐播放」可随时预览三种效果：
   - 充电预览会完整跑一遍录屏里的时序（正在充电 65% → 快速充电 65.5x% → 超快充电 → 收缩消失），约 7.5s 后自动结束预览；
   - 计时器预览持续计时，**点击胶囊可展开/收起**；
   - 音乐预览带封面与波形，点击胶囊展开播放器（上一首/暂停/下一首可点击）。
4. 真实场景：
   - 插上充电器（仅插入瞬间触发一次，不会因电量变化反复弹出）；6 秒后自动收起成圆点再消失，与录屏一致；
   - 系统时钟 App 的秒表/计时器运行时（通知使用权已授予），岛内出现计时胶囊；暂停时不再自己走字；
   - 任意音乐 App 播放/暂停时，通过 MediaSession 读取封面、标题、歌手、进度；暂停时保留胶囊；
   - 预览模式会在 60s 后自动退出，不会影响真实事件。

## 1:1 还原的关键实现

### 尺寸按「屏宽比例」标定
三段录屏是同一台手机的全屏宽顶部裁切，因此所有尺寸都以 **屏幕宽度 W 的比例** 定义（不是固定 dp），
这样在任意屏幕上都能得到和录屏完全一致的比例。以下数字来自 `../analysis/video/REPORT.md` 的逐帧实测：

| 元素 | 实测（占 W） | 代码位置 |
|---|---|---|
| 胶囊高度 | 0.0892–0.0896 W | `IslandSpec.HC` |
| 胶囊宽度（音乐/计时器） | 0.3664 / 0.3687 W | `IslandSpec.compactW()` |
| 无内容小胶囊（收起中间态） | 0.244 W | `IslandSpec.minPillW()` |
| 展开卡片宽度 | 0.9799 / 0.9806 W | `IslandSpec.expandedW()` |
| 音乐展开高度 | 0.4386 W | `IslandSpec.musicExpandedH()` |
| 计时展开高度 | 0.2469 W | `IslandSpec.timerExpandedH()` |
| 展开卡片圆角 | 0.0739～0.0742 W（两卡片同绝对圆角） | `IslandSpec.expandedRadius()` |
| 顶部间距 | 0.0099 W | `IslandSpec.TOP` |
| 充电池宽度 | 0.5266 W | `IslandSpec.chargingW()` |

内容尺寸同样按实测比例：计时胶囊图标 0.63×胶囊高、秒表读数 0.282×胶囊高；展开计时卡片图标/按钮 0.474×卡片高、
读数 0.137×卡片高；音乐胶囊封面 0.663×胶囊高、5 根波形条 12~13px 宽/23.5px 间距（bar1~5 实测幅度范围）；
展开音乐卡片封面 0.136×卡宽、标题帽高 0.091×卡高、进度条 0.161–0.844×卡宽、五个按钮中心 0.100/0.296/0.496/0.695/0.893。

### 动画曲线（逐帧拟合）

| 过渡 | 参考录屏实测 | 实现 |
|---|---|---|
| 弹出（圆点→胶囊，v2） | 参考：105→1034px，+2.4% 回弹、约 530ms 收敛 | 真·弹簧物理 `k=200, ζ=0.66`：宽度 +6.2% 回弹（约 280ms 到峰），约 0.55s 稳定；内容额外 0.38s 弹入 |
| 收回（胶囊→圆点，v2） | 参考：内容瞬间消失、收缩后保持圆点 | 真·弹簧 `k=380, ζ=0.62`：收缩时先冲过圆点 8% 再弹回，弹性明显 |
| 展开（胶囊→大卡，v2） | 参考：1184→3190px，单调 ~330-380ms | 弹簧 `k=260, ζ=0.72`：+3.7% 过冲，约 0.5s 稳定；内容以 0.86→1 弹入 |
| 收起（大卡→胶囊，v2） | 参考：先缩到 0.244W 空胶囊再弹回 0.366W | 弹簧 `k=280, ζ=0.52`：下冲 15%（约 0.30W 最小宽）后回弹到胶囊，与录屏的“弹簧式收起”一致 |
| 快充光爆 | 一次性包络：0.9s 上升 + 1.1s 衰减，峰值 ~32% 透明度，半径 ~0.45 胶囊宽 | `drawChargingGlow()` 时序包络（非循环） |

曲线实现见 `Curves.java`（解析解阻尼振子步响应 + 三次贝塞尔采样），
与参考视频逐帧对比见 `../preview/curves_fit.png`。

### 视觉细节（来自逐帧取样）
- 卡片纯黑 `#000000`、无描边无阴影；**v3.4 起所有状态（含计时展开卡、通知卡）均为完全不透明黑卡**（参考录屏里计时卡底部约 62% 黑，已按用户要求改为不透明）。
- 计时器：琥珀色圆角方块底 `#462C0E` + 橙色秒表图形 `#FAA427`；展开卡片内橙色氛围光、副标题 `#587185`、两个 0.474×卡片高 的圆形按钮（浅灰播放 `#CDCDD0` / 橙色暂停 `#FE9043`）。
- 音乐：胶囊内 0.663×卡片高 的圆角封面 + 右侧 5 根红粉渐变小节拍条（圆头，宽度=间距×0.52，中心条幅度最大）；
  展开卡片内圆角封面、标题/歌手、白色进度条、五个等距按钮（应用图标圆 / 上一首 / 暂停 / 下一首 / 心形）；
  背景是取封面主色的红色氛围渐变（自动从 MediaSession 封面图取色）。
- 充电：左侧白色加粗状态文案（正在充电/快速充电/超快充电），右侧电量（快速/超快时显示两位小数），
  最右侧闪电图标：普通充电为单闪电绿色 `#34D889`（无光晕），快速/超快为双闪电黄色 `#DEC640` + 一次性光爆；
  文案/电量按录屏节奏切换。

### 状态触发（真机）
- 充电：`BATTERY_CHANGED / POWER_CONNECTED` 广播（按插拔边沿触发一次）；电量小数由 `BATTERY_PROPERTY_CHARGE_COUNTER` 估算，
  充电功率由 `BATTERY_PROPERTY_CURRENT_NOW` 分档（≥5A 超快充、≥2A 快充）。
- 计时器：`NotificationListenerService` 识别系统时钟的秒表/计时器通知（chronometer / 关键字 / 时钟包名），
  读取 `Notification.when` + `android.chronometerCountDown` 自行 1Hz 计算读数；暂停（无 chronometer）时不走字。
  通知监听断开时自动 requestRebind，并在服务启动时回放已存在的计时通知。
- 音乐：`MediaSessionManager.getActiveSessions()`（通知使用权授权）读封面/标题/歌手/进度/播放态，
  `MediaController.Callback` 实时更新；暂停保留胶囊；海报无封面时清空旧封面。
