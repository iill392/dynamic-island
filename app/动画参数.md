## 1. 三层结构（与手册 §1 一致）

| 层 | 驱动什么 | 机制 | 代码 |
|---|---|---|---|
| 几何层 | 卡片宽 × 高（+圆角） | 双轴独立**阻尼弹簧** | `Spring.java` + `IslandView.frameCallback` |
| 缓动层 | 内容透明度 | cubic-bezier | `IslandEase.java` + `Fade.java` |
| 时序层 | 各段何时开始/持续多久 | 固定毫秒常量 | `IslandView` 常量区 |

几何层不用缓动曲线 —— cubic-bezier 值域单调趋近 1，数学上无法过冲。

## 2. 几何层：双轴弹簧（§2.2 参数表原样）

```
x'' = -k (x - target) - c x'        c = 2ζ√k
半隐式欧拉：v += (-k(x-target) - c·v) · dt;   x += v · dt
dt 上限 32ms（Spring 调用方 clamp）
```

| 场景 | 轴 | ζ | k | ω | ω_d | 峰值时刻 π/ω_d | 过冲/欠冲 |
|---|---|---|---|---|---|---|---|
| 展开（释放） | 宽 | 0.58 | 110 | 10.49 | 8.55 | 368 ms | +10.7% |
| 展开（释放） | 高 | 0.62 | 320 | 17.89 | 14.03 | 224 ms | +8.4% |
| 收起（按压） | 宽 | 0.47 | 165 | 12.85 | 11.34 | 277 ms | −18.8% |
| 收起（按压） | 高 | 0.55 | 320 | 17.89 | 14.94 | 210 ms | −12.6% |

代码：

```java
private static final float RELEASE_W_ZETA = 0.58f;  private static final float RELEASE_W_K = 110f;
private static final float RELEASE_H_ZETA = 0.62f;  private static final float RELEASE_H_K = 320f;
private static final float PRESS_W_ZETA  = 0.47f;   private static final float PRESS_W_K  = 165f;
private static final float PRESS_H_ZETA  = 0.55f;   private static final float PRESS_H_K  = 320f;
```

- 宽高各一套 ζ/k → 视觉上「先垂直张开，再横向拉开」（高度 ~0.27s 到位，宽度 ~0.60s 稳定）。
- 圆角用高度轴的 ζ/k 跟随，目标圆角：胶囊 = h/2，大卡 = 0.0740 × 屏宽。
- 稳定判定：`|Δpos| < 5px && |v| < 120px/s`，命中后强制吸附目标值（手册 §2.5）。

实测收敛时间（60fps、dt clamp 32ms）：

| 过渡 | 稳定耗时 |
|---|---|
| 展开 宽 0.3675W → 0.980W | ~600 ms |
| 展开 高 胶囊 → 大卡 | 267–317 ms |
| 收起 宽 0.980W → 0.3675W | ~650 ms |
| 收起 高 大卡 → 胶囊 | ~333 ms |
| 弹出 宽 圆点 → 充电胶囊 | ~583 ms |
| 收回 宽 胶囊 → 圆点 | ~600 ms |

## 3. 窗口余量（§2.6）

```java
SPRING_HEADROOM = 1.18f;   SHADOW_PAD_DP = 6;
窗口宽 = (目标卡片宽 + 2×6dp) × 1.18
窗口高 = 卡片顶距 + (目标卡片高 + 2×6dp) × 1.18
```

窗口宽度和高度都按当前目标卡片的最大值算（展开时用大卡、胶囊时用胶囊），
所以 +10.7% 的宽度过冲不会被自己的窗口裁掉。
窗口 `gravity = TOP | CENTER_HORIZONTAL`，卡片顶边固定在状态栏位置上（手册 §10.6：不能用垂直居中，会瞬移）。

## 4. 缓动层（§3）

```java
IslandEase.STANDARD = cubic-bezier(0.40, 0.00, 0.20, 1.00)   // 药丸/内容 淡出
IslandEase.CONTENT  = cubic-bezier(0.20, 0.00, 0.30, 1.00)   // 内容 淡入
```

求解器：Newton-Raphson 8 次迭代（ε=1e-5），失败退化二分 24 次（`IslandEase.java`）。
缓动只作用于内容透明度，不作用于尺寸。

## 5. 时序层：淡入淡出调用表（§4-§5 原样）

| 时机 | 目标 | alpha | 时长 | 延迟 | 曲线 |
|---|---|---|---|---|---|
| 弹出（从圆点出现） | 内容 | 0 → 1 | `CONTENT_MS` 340 ms | 75 ms | CONTENT |
| 展开 | 旧胶囊内容 | 1 → 0 | `POP_MS` 150 ms | 0 | STANDARD |
| 展开 | 大卡内容 | 0 → 1 | 340 ms | 60 ms | CONTENT |
| 收起 | 大卡内容 | 1 → 0 | 170 ms | 0 | STANDARD |
| 收起 | 胶囊内容 | 0 → 1 | **90 ms**（弹簧稳定后） | 0 | CONTENT |
| 隐藏 | 当前内容 | 1 → 0 | 170 ms | 0 | STANDARD |

```java
CONTENT_MS=340; POP_MS=150; COLLAPSE_OUT_MS=170; COLLAPSE_IN_MS=90;
HIDE_OUT_MS=170; SHOW_DELAY_MS=75; EXPAND_DELAY_MS=60;
```

## 6. 窗口属性（§10.7）

```java
lp.windowAnimations = 0;
// PRIVATE_FLAG_NO_MOVE_ANIMATION = 0x40，通过反射设置（隐藏 API 被 ROM 拦截时静默跳过）
```

这两项缺一个，系统就会自己"搬动/缩放"悬浮窗，看起来像瞬移或跳位。

## 7. 与手册不一致处（工程适配）

- 手册示例的展开卡片是 972×660 px（450×108 胶囊），对应它的卡片尺寸常量；
  本项目卡片尺寸仍按参考视频逐帧测量（胶囊 0.3675W×0.0892W、大卡 0.980W×0.247W/0.4386W），
  只套用手册的弹簧/缓动/时序/窗口余量参数。
- 手册 §7 的探针轨迹与 §2.2 公式推算不完全一致（例如 §7 展开宽度峰值只写了 +2px），
  本实现以 §2.2 参数表与公式为准，实测（60fps 离散积分）为宽度 +8.8%、高度 +5.0%，
  比理论值略小是半隐式欧拉离散化误差，峰值时刻 350ms/200ms 与理论 368ms/224ms 对应。
- 弹出（圆点→胶囊）也使用"释放"轴参数；收回/隐藏使用"按压"轴参数。
